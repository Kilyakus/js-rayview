# RayView.js - v1.2610.09617

Reactive rays on Web Audio in one file and without dependencies: a self-building equalizer (its own canvas, Web Audio on the first play), the engine inside it and the template registry. Works in its own container, in a PadView background and as the backdrop of PlayView.
